# 전처리 및 참고자료

이 문서는 공개 저장소에 남겨둔 전처리 관련 파일들이 어떤 용도인지 구분해서 보기 위한 참고 문서입니다.

## 현재 앱 런타임에 직접 연결되는 자원

### `preprocessing_data/preprocessing/`

- 앱이 기본적으로 읽는 정제 CSV가 들어 있습니다.
- Streamlit 화면 실행에는 이 폴더가 가장 직접적인 입력입니다.

### `preprocessing_code/data/`

- `disaster_message_realtime.csv`
  - 실시간 안내 페이지 입력용 재난문자 CSV입니다.
  - 크롤링 결과 또는 모의 재난문자 생성 결과가 이 스키마로 맞춰집니다.
- `Emergency_shelter.db`
  - 분석 페이지에서 참조하는 보조 DB입니다.

### `preprocessing_code/shelter_type_layer_map1.html`

- 데이터 분석 페이지에서 임베드하는 지도 HTML입니다.
- 시각화 산출물을 앱 화면에서 바로 재사용하기 위해 저장소에 포함했습니다.

## 전처리 이력과 참고용으로 남겨둔 자원

### `preprocessing_code/raw/`

- 원본 또는 원본에 가까운 입력 CSV를 보관합니다.
- 현재 앱이 직접 읽지는 않지만, 어떤 출발 데이터에서 정제가 시작되었는지 확인할 수 있습니다.

### `preprocessing_code/jupyter/` 및 루트의 `*.ipynb`

- 전처리, 분석, 실험 과정에서 사용한 노트북입니다.
- 코드 이력과 탐색 과정을 확인하는 용도로 유지합니다.

### `preprocessing_code/py/`

- API 수집이나 데이터 가공 과정에서 사용한 보조 스크립트입니다.
- 현재 앱 런타임보다 전처리 재현과 작업 기록에 더 가깝습니다.

### `preprocessing_code/shelter_map.html`

- 지도 관련 산출물 중 참고 성격이 큰 HTML입니다.
- 앱이 직접 쓰는 핵심 파일은 `shelter_type_layer_map1.html`이고, 나머지는 비교/이력용으로 남겨둡니다.
