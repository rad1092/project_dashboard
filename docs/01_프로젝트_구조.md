# 프로젝트 구조

이 저장소는 Streamlit 앱 실행 코드와, 그 앱이 기대하는 전처리 산출물 및 전처리 참고 자료를 함께 보관하는 형태로 구성되어 있습니다.

## 루트 기준 주요 구성

```text
.
|- app.py
|- pages/
|- preprocessing_code/
|- preprocessing_data/
|- docs/
|- .streamlit/
|- packages.txt
|- pyproject.toml
`- uv.lock
```

## 디렉터리별 역할

### `app.py`

- Streamlit 진입점입니다.
- 홈 화면을 구성하고 공용 데이터 로더를 제공합니다.
- 기본 전처리 데이터 경로는 저장소 내부 `preprocessing_data`이며, 필요하면 `.streamlit/secrets.toml`의 `preprocessing_data_dir`로 덮어쓸 수 있습니다.

### `pages/`

- `1_대피_안내_시뮬레이션.py`
  - 정적 전처리 데이터 기준으로 대피소 추천과 경로 탐색을 수행합니다.
- `2_실시간_대피_안내.py`
  - 재난문자 CSV를 읽어 최근 경보 기반 안내를 제공합니다.
  - 필요 시 `preprocessing_code/mock_disaster_message.py`를 통해 모의 재난문자 데이터를 생성해 같은 흐름으로 사용할 수 있습니다.
- `3_데이터_분석.py`
  - 전처리 CSV, 지도 HTML, 참조 DB를 조합해 분석 화면을 구성합니다.

### `preprocessing_data/`

- 앱이 직접 읽는 정제 데이터가 들어 있습니다.
- 현재 공개 저장소에서도 실행 가능한 기본 데이터 세트 역할을 합니다.
- 핵심 파일은 `preprocessing_data/preprocessing/*.csv`입니다.

### `preprocessing_code/`

- 전처리 스크립트, 크롤링 코드, 원본 데이터, 노트북, 참고 산출물을 함께 보관합니다.
- 앱 실행에 직접 연결되는 파일도 일부 포함합니다.
- 예:
  - `crawling.py`: 실시간 재난문자 Selenium 크롤러
  - `mock_disaster_message.py`: 모의 재난문자 CSV 생성기
  - `data/disaster_message_realtime.csv`: 실시간 안내 페이지 입력 CSV
  - `data/Emergency_shelter.db`: 분석 페이지 참조 DB
  - `shelter_type_layer_map1.html`: 분석 페이지 지도 임베드 파일

### `docs/`

- GitHub 공개용 설명 문서 모음입니다.
- 앱 구조, 데이터 흐름, 전처리 및 참고 자료의 성격을 문서화합니다.

### `.streamlit/`

- `config.toml`에 테마와 브라우저 설정이 있습니다.
- `secrets.toml.example`은 로컬 비밀 설정 예시 파일입니다.

## 공개 저장소에서의 보존 원칙

- `preprocessing_code/`와 `preprocessing_data/`는 의도적으로 유지합니다.
- 목적은 "앱이 어떤 입력을 사용하고, 그 입력이 어떤 전처리 과정을 거쳐 만들어졌는지"를 함께 보여주기 위함입니다.
- 따라서 이 저장소는 단순 배포본이라기보다, 실행 가능한 앱과 전처리 참고 자료를 함께 담은 공개 아카이브에 가깝습니다.
